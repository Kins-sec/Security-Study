# SIEM 기본 개념

## 1. 학습 목적
보안 이벤트를 수집하고 분석하는 SIEM의 기본 개념을 이해한다.

## 2. 핵심 개념
- SIEM은 여러 시스템과 보안 장비에서 발생하는 로그를 수집하고 분석하는 시스템이다.
- 다양한 로그를 통합하여 보안 위협이나 이상 징후를 탐지하는 데 활용한다.
- 보안관제 담당자는 탐지된 이벤트를 확인하고 분석하여 대응한다.

## 3. 주요 기능
- 로그 수집 및 통합
- 보안 이벤트 분석
- 이상 행위 탐지
- 보안 이벤트 모니터링 및 보고

## 4. 관련 도구
- Wazuh
- Splunk
- IBM QRadar

## 5. 면접 질문
Q. SIEM이란 무엇인가요?

A. 여러 시스템과 보안 장비에서 발생하는 로그를 수집하고 분석하여 보안 위협이나 이상 징후를 탐지하는 시스템입니다.
