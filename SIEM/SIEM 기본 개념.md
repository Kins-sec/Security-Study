# SIEM 기본 개념

## 1. 학습 목적

SIEM의 기본 개념과 주요 기능을 이해하고, 보안관제 업무에서 로그 수집 및 분석이 어떤 역할을 하는지 학습한다.

## 2. SIEM이란?

SIEM(Security Information and Event Management)은 여러 시스템과 보안 장비에서 발생하는 로그와 보안 이벤트를 수집하고 분석하여 보안 위협을 탐지하는 시스템이다.

## 3. SIEM의 주요 기능

### 로그 수집

서버, 방화벽, 네트워크 장비 등 여러 시스템에서 발생하는 로그를 수집한다.

### 로그 분석

수집한 로그를 분석하여 정상적인 활동인지 의심스러운 활동인지 확인한다.

### 이벤트 상관분석

여러 시스템에서 발생한 이벤트를 서로 연관 지어 분석하여 개별 로그만으로 파악하기 어려운 보안 위협을 확인한다.

예를 들어 같은 IP에서 로그인 실패가 반복된 후 로그인이 성공하고, 이후 내부 서버에 접속하는 상황이 발생했다면 여러 이벤트를 연관 지어 계정 탈취 가능성을 의심할 수 있다.

### 위협 탐지 및 알림

미리 설정된 탐지 규칙에 따라 의심스러운 활동을 발견하면 보안 담당자에게 알림을 제공한다.

예를 들어 5분 동안 로그인 실패가 10회 이상 발생하면 알림이 발생하도록 규칙을 설정할 수 있다.

### 로그 보관 및 시각화

수집한 로그를 보관하여 과거 보안 이벤트를 확인할 수 있으며, 대시보드를 통해 보안 이벤트와 로그 현황을 쉽게 파악할 수 있다.

## 4. 보안관제에서의 활용

보안관제 담당자는 SIEM에서 탐지된 보안 이벤트를 확인하고 관련 로그를 분석하여 실제 위협인지 판단한다.

예를 들어 특정 IP에서 로그인 실패가 반복적으로 발생한 경우, 이후 로그인 성공 여부와 접속 위치, 접속한 시스템 등을 함께 확인하여 비정상적인 접근인지 분석할 수 있다.

또한 SIEM에서 탐지된 모든 이벤트가 실제 공격은 아니다. 정상적인 활동이 위협으로 잘못 탐지되는 오탐(False Positive)이 발생할 수 있으므로 관련 로그와 상황을 추가로 확인하는 과정이 중요하다.

## 5. 내가 학습한 점

이번 학습을 통해 SIEM은 여러 시스템에서 발생하는 로그를 한곳에 모아 분석하고 보안 위협을 탐지하는 시스템이라는 것을 이해하였다.

또한 하나의 로그만 확인하는 것이 아니라 여러 시스템에서 발생한 이벤트를 함께 분석하면 보안 위협을 더 정확하게 파악하는 데 도움이 된다는 것을 배웠다.

보안관제 업무에서는 SIEM이 탐지한 이벤트를 그대로 판단하기보다 관련 로그와 발생 상황을 확인하여 실제 위협인지 분석하는 과정이 중요하다는 점을 학습하였다.
