# Linux 사용자 관리 실습

## 목적

Linux 환경에서 사용자 생성, 확인, 삭제 과정을 실습하고 계정 관리 방법을 이해한다.

## 환경

- OS: Ubuntu Server 26.04
- Virtualization: VMware Workstation

---

# 1. 사용자 생성

## 명령어

sudo adduser testuser

## 설명

`adduser` 명령어를 사용하여 Linux 시스템에 새로운 사용자 계정 `testuser`를 생성한다.

사용자 생성 과정에서 계정 비밀번호와 기본 사용자 정보를 설정하며, 생성된 계정은 Linux 시스템에서 사용할 수 있는 상태가 된다.

# 2. 사용자 정보 확인

## 명령어

id testuser

## 설명

`id` 명령어를 사용하여 생성된 사용자의 UID(User ID), GID(Group ID), 그룹 정보를 확인한다.

이를 통해 사용자가 정상적으로 생성되었는지 확인하고 계정 관련 정보를 확인할 수 있다.

# 3. 사용자 삭제

## 명령어

sudo deluser --remove-home testuser

## 설명

`deluser` 명령어를 사용하여 생성된 사용자 계정을 삭제한다.

`--remove-home` 옵션을 사용하면 사용자 계정뿐만 아니라 해당 사용자의 홈 디렉터리(`/home/testuser`)까지 함께 삭제하여 관련 데이터를 정리할 수 있다.

# 4. 사용자 삭제 확인

## 명령어

id testuser

## 설명

삭제한 사용자 계정이 Linux 시스템에서 정상적으로 제거되었는지 확인한다.

삭제가 완료된 경우 해당 사용자가 존재하지 않는다는 메시지가 출력된다.

# 5. 보안 관점

Linux 서버에서 사용자 계정 관리는 중요한 보안 요소이다.

- 불필요한 계정은 공격자가 악용할 수 있는 접근 경로가 될 수 있다.
- 사용하지 않는 계정이나 퇴사자의 계정은 삭제 또는 비활성화해야 한다.
- sudo 권한 부여 시 권한 상승 위험이 있으므로 최소 권한 원칙을 적용해야 한다.
- 사용자 생성 및 삭제 기록은 로그 분석을 통해 추적할 수 있다.
