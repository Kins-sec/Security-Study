# SSH 이상 로그인 탐지 실습

## 목적

Linux 서버의 SSH 인증 로그를 분석하여 비정상 로그인 시도를 탐지한다.

## 환경

- Ubuntu Server 26.04
- VMware Workstation

## SSH 로그인 로그 확인

명령어

sudo journalctl -u ssh

## 비밀번호 실패 로그인 탐지

명령어

## 보안 관점

- 반복적인 로그인 실패는 Brute Force 공격 가능성이 있다.
- 비정상 IP에서 발생한 로그인 시도는 모니터링이 필요하다.
- SSH 로그 분석은 보안관제 업무에서 중요한 모니터링 항목이다.
