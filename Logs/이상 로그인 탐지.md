# SSH 이상 로그인 탐지 실습

## 목적

Linux 서버의 SSH 인증 로그를 분석하여 비정상적인 로그인 시도를 탐지하고, 실패한 로그인 이벤트를 확인하는 과정을 실습한다.

## 환경

- Ubuntu Server 26.04
- VMware Workstation

---

# 1. SSH 로그인 로그 확인

## 명령어

sudo journalctl -u ssh

**그림 1. SSH 로그인 로그 확인**

## 설명

`journalctl` 명령어를 사용하여 SSH 서비스에서 발생하는 인증 로그를 확인한다.

SSH 로그에는 사용자 로그인 성공 및 실패 기록이 저장되며, 이후 발생하는 로그인 이벤트를 분석하기 위한 기본 로그를 확인한다.

**그림 2. SSH 로그인 실패 이벤트 발생**

실제 서버 환경에서는 반복적인 로그인 실패가 발생할 경우 Brute Force 공격 또는 비인가 접근 시도로 판단할 수 있다.

# 3. 최근 시간 범위 로그 조회

## 명령어

sudo journalctl -u ssh --since "5 minutes ago"

## 실행 결과

<img width="1256" height="355" alt="실패 로그 확인" src="https://github.com/user-attachments/assets/c5263f0a-1458-4de9-baf8-ee87f5a2c980" />


**그림 3. 최근 SSH 인증 로그 조회**

## 설명

`--since "5 minutes ago"` 옵션을 사용하여 최근 5분 동안 발생한 SSH 관련 로그만 조회한다.

전체 로그가 아닌 특정 시간 범위의 이벤트를 확인하여 방금 발생시킨 로그인 실패 기록을 분석한다.

## 확인 내용

- 이벤트 발생 시간
- 로그인 시도 계정
- 접속 IP 주소
- 인증 성공/실패 여부

# 보안 관점

SSH는 Linux 서버 원격 관리에 사용되는 주요 서비스이며 공격자가 접근을 시도하는 주요 대상이다.

반복적인 로그인 실패 이벤트는 Brute Force 공격 가능성이 있으므로 지속적인 모니터링이 필요하다.

보안관제 환경에서는 SSH 인증 로그를 기반으로 다음 항목을 분석한다.

- 비정상적인 로그인 시도 탐지
- 공격 IP 확인 및 차단
- 계정 보안 상태 확인
- 인증 실패 이벤트 모니터링

---

# 실습 결과

Linux 환경에서 SSH 인증 로그를 확인하고, 의도적으로 로그인 실패 이벤트를 발생시킨 후 시간 범위 기반으로 로그를 조회하여 실패 인증 기록을 분석하였다.

이를 통해 SSH 로그 분석 방법과 보안관제 업무에서 필요한 이상 로그인 탐지 과정을 이해하였다.
