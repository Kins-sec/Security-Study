# Firewall (방화벽)

## 1. 학습 목적
방화벽의 역할과 네트워크 접근 제어 방식을 이해한다.

## 2. 핵심 개념
방화벽은 네트워크 트래픽을 설정된 보안 정책에 따라 허용하거나 차단하는 보안 장비 또는 기능이다.

## 3. 주요 기능
- IP 주소 기반 접근 제어
- 포트 및 프로토콜 기반 접근 제어
- 허용되지 않은 트래픽 차단

## 4. 면접 질문
Q. 방화벽이란 무엇인가요?

A. 네트워크 트래픽을 설정된 보안 정책에 따라 허용하거나 차단하여 외부의 비인가 접근을 통제하는 보안 장비입니다.
