# XSS / CSRF

## 1. 학습 목적
웹 취약점 공격인 XSS와 CSRF의 차이점을 이해한다.

## 2. 핵심 개념
- XSS: 웹페이지에 악성 스크립트를 삽입하여 다른 사용자의 브라우저에서 실행되도록 하는 공격
- CSRF: 사용자가 로그인한 상태를 악용하여 사용자의 의도와 관계없이 특정 요청을 수행하도록 유도하는 공격

## 3. 차이점
- XSS: 악성 스크립트 실행을 유도하는 공격
- CSRF: 정상 사용자의 인증 상태를 악용하는 공격

## 4. 대응 방법
- XSS: 출력값 인코딩, 입력값 검증, 보안 정책 적용
- CSRF: CSRF 토큰 사용, 요청 출처 검증, 쿠키 보안 설정

## 5. 면접 질문
Q. XSS와 CSRF의 차이는 무엇인가요?

A. XSS는 악성 스크립트를 사용자의 브라우저에서 실행시키는 공격이고, CSRF는 사용자의 인증 상태를 악용해 의도하지 않은 요청을 수행하게 만드는 공격입니다.
