# SQL Injection

## 1. 학습 목적
SQL Injection 공격의 원리와 대응 방법을 이해한다.

## 2. 핵심 개념
SQL Injection은 웹사이트의 입력값 검증이 제대로 이루어지지 않은 경우, 공격자가 악의적인 SQL 구문을 삽입하여 데이터베이스에 비정상적인 명령을 실행하도록 유도하는 공격이다.

## 3. 주요 피해
- 비인가 데이터 조회
- 데이터 변조 및 삭제
- 인증 우회

## 4. 대응 방법
- Prepared Statement 사용
- 사용자 입력값 검증
- 데이터베이스 계정 권한 최소화

## 5. 면접 질문
Q. SQL Injection이란 무엇인가요?

A. 사용자 입력값에 악의적인 SQL 구문을 삽입하여 데이터베이스에 비정상적인 명령을 실행하도록 유도하는 공격입니다.
